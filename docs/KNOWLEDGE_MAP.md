# Knowledge map

Naijin-Ryū is not only a combat syllabus. Its original texts describe multiple linked domains which must remain distinct:

| Domain | Primary source | Scope |
| --- | --- | --- |
| Martial ethics | `Naijin-Ryū Manual .docx` §I | Guard Life, Not Ego; Centerline Ascension; Shadow Integration; Skill as Sacrament |
| Martial structure | Manual §§II–III, XII | Sashes of Dawn, SURGE, Rule of Tens |
| Body mechanics | `Stances for Naijin-Ryū.pdf` | Two proposed stance families, alignment and mobility |
| Training | `Phases of SURGE Training Manual.docx`, `Phase 1 Fundamentals.pdf`, solo-intensive syllabus | Parallel phases and schedules |
| Mental conditioning | `Naijin-Ryū Phase1 Mental Conditioning.docx` | Breath, attention, reflection and journaling |
| Spiritual doctrine | True Ascension guides; Church foundational package | Pleroma, Divine Spark, Aeons, Archons, Shadow Walkers |
| Applied spiritual practice | Aeon Key and other True Ascension texts | Reflective exercises and voluntary practice |
| Organization | Church foundational package | Proposed clergy, governance, incorporation and bylaws |
| Operations | Camps overview and dojo extension materials | Proposals, not approved operations |
| Restricted source | `Clear Intent` manual | Last-resort lethal-force source held for safety review, not presented as public instruction |

## Distinctions to preserve

**Doctrine ≠ evidence.** A statement is not scientifically verified because a manual asserts it.

**Proposal ≠ institution.** Corporate names, construction plans and camp designs do not prove incorporation, permission or existence.

**Edition ≠ correction.** Conflicting versions remain separately attributed until the author makes a decision.

**Optional ≠ mandatory.** The Church package describes spiritual interpretation and martial participation as voluntary.

**Sash ≠ Aeon.** Technical-rank progression and stages of spiritual transformation are different systems.

This layout is an editorial proposal and does not revise the creator's doctrine.
