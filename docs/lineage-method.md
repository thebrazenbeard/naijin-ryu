## Root-of-document versus source-of-truth

The earliest modified file in a folder is not necessarily the conceptual origin. A later file can synthesize older material without proving direct descent from a particular draft. A date assigned by a filesystem is **file metadata** (which may reflect copying or editing), not proof of when an idea first existed.

## Evidence levels

- **DIRECT_SOURCE:** a supplied document or current explicit user statement.
- **METADATA:** observed hash, byte count, path, last-write timestamp, source reference, Ingest receipt.
- **SUPPORTED_INFERENCE:** a content/terminology comparison; not a documented derivation unless an explicit trail proves it.
- **UNKNOWN:** earliest actual origin, missing source drafts, legal filing status, chronological drafting causal links and PDF/Word semantic identity where not compared.

## Privacy and installation boundaries

The raw OneDrive corpus belongs in a **private** Ingest store. Public GitHub receives appropriate educational syntheses and redacted provenance records, not all originals or private local paths. Source code being available in Ingest and Roots does not prove their runtime is always active, deployed, or automatically integrated into GitHub; any run must be explicitly recorded and verified.
