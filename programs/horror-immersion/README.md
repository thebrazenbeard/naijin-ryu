# Immersive horror experience — separate historical concept

**Classification:** **Not a Naijin-Ryū program** · **Source:** NRY-001 / NRY-002 (the *Camps Overview* Word/PDF pair) · **Development status:** no assigned active workstream

The historical camp planning document discusses two distinct ideas: a Naijin-Ryū martial arts camp for youth and a fall/winter fictional slasher-movie survival experience for teens and adults. **The horror experience was never established here as a branch of Naijin-Ryū's martial discipline, True Ascension worldview, Church foundation, or community program.** Their appearance in the same document proves co-location of proposed plans, not membership in the same system.

The horror concept includes an immersive narrative weekend, performers, puzzles, simulated threat, explicit consent boundaries, opt-outs and decompression. Those are descriptions of an exploratory source proposal, **not an active, approved, insured or operating attraction**.

A development branch named `program/horror-immersion` was created on 2026-10-21 because I mistakenly treated the document's two proposals as two Naijin-Ryū programs. That Git ref remains in place but is **parked**. Its existence does not assign this concept to Naijin-Ryū. No future changes should target it as a Naijin-Ryū program without Patrick's further direction.

This page remains only to preserve traceability and document the corrected boundary. A separately authorized choice can eventually move the concept to an independent project, retain it as historical research, or retire the existing Git branch without rewriting the original source.
