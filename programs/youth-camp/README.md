# Naijin-Ryū youth summer camp

**Work branch:** `program/youth-camp` · **Integrated authority:** [`main`](../../README.md) · **Workstream status:** CONCEPT-ONLY

This workstream is a historical **proposed** summer/overnight program for children and youth, described in the *Camps Overview*. Its source contains martial and inner-development activities, supervision and staffing ideas, approximate enrollment capacity, daily scheduling and a camp health and safety checklist.

**Primary public-indexed sources:** NRY-001 and NRY-002, the camp proposal's Word and PDF forms. These are not independent operating permits.

**Existing guides:** [combined camp proposals](../../docs/organization/program-concepts.md), [regulatory and safety evidence](../../docs/research-evidence.md), [martial foundation](../martial-training/README.md).

**Next research/development:** verify applicability of Indiana youth camp rules to a concrete program design; define age groups, parental permission, qualified supervision and staff-screening expectations; separate physical-contact teaching from spiritual participation; draft incident-response and safeguarding criteria.

**Boundary:** the conceptual camp is not open, licensed, insured or approved on the strength of this source. Never create child records, enrollment, recruitment or real-world program claims in this public branch without separate authority.
