## Historical concept outside Naijin-Ryū

The [immersive horror proposal](horror-immersion/README.md) is **not one of the five Naijin-Ryū workstreams**. It was listed in the same source document as the youth camp, which does not give it an affiliation with the martial or spiritual system. Its preexisting `program/horror-immersion` Git ref is retained as a parked historical ref, without active Naijin-Ryū ownership or assigned development.

The program landing pages are **navigation and decision registers**, not substitutes for the original manuscripts or proof of operating programs. Protected personal material remains private, regardless of branch.
