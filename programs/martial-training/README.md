# Martial arts and SURGE

**Work branch:** `program/martial-training` · **Integrated authority:** [`main`](../../README.md) · **Workstream status:** SOURCE-BASED DEVELOPMENT

This workstream covers the Naijin-Ryū martial program: the four protected ethical principles, five SURGE pillars, five Sashes of Dawn, phase calendars, non-harmful practice design, assessment and recovery planning. The working calendar is three eight-week student phases followed by an open Guardian phase; original six- and twelve-week versions remain source-traceable alternatives. Calendar time does not grant rank.

**Primary public-indexed sources:** NRY-007, NRY-009, NRY-010, NRY-012, NRY-013, NRY-014 and NRY-016. The particularly dangerous last-resort source remains restricted, not part of this public program file.

**Existing guides:** [ethics and ranks](../../docs/ethos-and-progression.md), [SURGE](../../docs/surge.md), [normalized curriculum](../../docs/curriculum.md), [manual chapter guide](../../docs/martial/manual-guide.md), [training logs](../../docs/training/session-templates.md).
